# My Linux & Cloud Learning Journey

This repository is my hands-on laboratory where I practice Linux system administration, automation, and Git workflows.

## 🛠️ Environment
* **OS:** Ubuntu Linux (Hosted via GitHub Codespaces)
* **Shell:** Bash
* **IDE:** Visual Studio Code

## 📁 Automation Scripts
* `first_script.sh`: Automatically checks server uptime, system load, and available storage space.

## 🚀 How to Run
To run this script, grant execution permissions and execute it in a Bash terminal:

```bash
chmod 700 first_script.sh
./first_script.sh
```
