# My Linux & Cloud Learning Journey

This repository is my hands-on laboratory where I practice Linux system administration, automation, and Git workflows.

## 🛠️ Environment
* **OS:** Ubuntu Linux (Hosted via GitHub Codespaces)
* **Shell:** Bash
* **IDE:** Visual Studio Code

## 📁 Automation Scripts
* `first_script.sh`: Automatically checks server uptime, system load, and available storage space.
* `workspace_setup.sh`: Automates the creation of a standardized project folder structure and configuration files.
* `server_deployer.sh`: Automates system package updates, installs the Nginx web server, and logs full output details to a custom log tracker.


## 🚀 How to Run
To run these scripts, grant execution permissions and execute them in a Bash terminal:

```bash
chmod 700 filename.sh
./filename.sh
```
